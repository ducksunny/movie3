# 🎬 영화 티어리스트 프로젝트 (Movie Tier List)

본 프로젝트는 사용자가 좋아하는 영화를 등급별(S, A, B, C)로 분류하고 관리할 수 있는 웹 어플리케이션입니다. 학습용 AI 도우미와 협업하여 기능을 점진적으로 개선하며 완성하였습니다.

## 🤖 사용 AI 정보
*   **이름:** Gemini 1.5 Flash
*   **역할:** 코드 작성, UI/UX 개선 제안, 버그 수정 및 기능 통합

## 🚀 주요 기능 및 선택 이유

### 1. 영화 카드 삭제 버튼 (X) 추가
*   **선택 이유:** 리스트를 관리하다 보면 잘못 추가하거나 더 이상 필요 없는 항목이 생깁니다. 이를 즉시 제거할 수 있는 기능을 추가하여 사용자 편의성을 높였습니다.

### 2. 티어별/미정 영화 실시간 개수 표시
*   **선택 이유:** 현재 내가 각 등급에 몇 개의 영화를 배치했는지, 아직 분류하지 않은 영화는 몇 개인지 한눈에 파악할 수 있도록 시각적 피드백을 강화했습니다.

### 3. 영화 이미지 보완 및 가독성 개선
*   **선택 이유:** 텍스트만 있는 카드보다 이미지가 있는 카드가 훨씬 직관적입니다. 외부 이미지 로딩 오류를 해결하기 위해 안정적인 Unsplash 소스를 사용하였고, 이미지 위에서도 제목이 잘 보이도록 **어두운 배경 레이어와 흰색 굵은 글씨**를 적용했습니다.

### 4. 입력 폼 UI 간소화
*   **선택 이유:** 이미지 주소를 직접 찾는 번거로움을 없애기 위해 '이미지 주소 입력창'을 제거했습니다. 이제 제목만 입력하면 자동으로 관련 이미지가 배정되어 사용이 훨씬 간편해졌습니다.

    const KEY = "movie-tier-final";
    const initialData = [

      { id: 'm4', title: '센과 치히로', tier: 'pool', img: 'https://images.unsplash.com/photo-1605806616949-1e87b487fc2f?w=200' },
      { id: 'm5', title: '엔드게임', tier: 'pool', img: 'https://images.unsplash.com/photo-1568833450751-fba3c6b2d129?w=200' },
      { id: 'm6', title: '범죄도시', tier: 'pool', img: 'https://images.unsplash.com/photo-1593032465175-481ac7f401a0?w=200' },
      { id: 'm7', title: '타이타닉', tier: 'pool', img: 'https://images.unsplash.com/photo-1500077423678-25eead4cb523?w=200' },
      { id: 'm8', title: '토이 스토리', tier: 'pool', img: 'https://images.unsplash.com/photo-1558679908-541bcf1249ff?w=200' }
    ];

    let state = { nextId: 9, items: [...initialData] };
    let selected = null;

    function save() { localStorage.setItem(KEY, JSON.stringify(state)); }
    function load() {
      const stored = localStorage.getItem(KEY);
      if (stored) state = JSON.parse(stored);
    }

    function render() {
      const tiers = ['S', 'A', 'B', 'C'];
      const tiersContainer = document.querySelector('#tiers');
      tiersContainer.innerHTML = '';
      
      tiers.forEach(tier => {
        const tierItems = state.items.filter(i => i.tier === tier);
        const row = document.createElement('div');
        row.className = `row ${tier}`;
        row.innerHTML = `
          <div class="label"><span>${tier}</span><small>${tierItems.length}개</small></div>
          <div class="drop" data-tier="${tier}"></div>
        `;
        const dropZone = row.querySelector('.drop');
        tierItems.forEach(item => dropZone.append(createCard(item)));
        
        dropZone.onclick = () => { if(selected) move(selected, tier); };
        dropZone.ondragover = e => e.preventDefault();
        dropZone.ondrop = e => move(e.dataTransfer.getData('text'), tier);
        
        tiersContainer.append(row);
      });

      const pool = document.querySelector('#pool');
      const poolItems = state.items.filter(i => i.tier === 'pool');
      pool.innerHTML = '';
      poolItems.forEach(item => pool.append(createCard(item)));
      document.querySelector('#pool-label').textContent = `아직 안 정한 영화 (${poolItems.length})`;
      
      pool.onclick = () => { if(selected) move(selected, 'pool'); };
      pool.ondragover = e => e.preventDefault();
      pool.ondrop = e => move(e.dataTransfer.getData('text'), 'pool');
    }

    function createCard(item) {
      const el = document.createElement('div');
      el.className = 'card';
      el.draggable = true;
      el.style.backgroundImage = `url('${item.img}')`;
      el.innerHTML = `
        <button class="del-btn" onclick="event.stopPropagation(); removeCard('${item.id}')">&times;</button>
        <div class="card-title">${item.title}</div>
      `;
      el.onclick = (e) => { e.stopPropagation(); selected = (selected === item.id) ? null : item.id; render(); };
      el.ondragstart = (e) => { e.dataTransfer.setData('text', item.id); selected = item.id; };
      return el;
    }

    function move(id, tier) {
      const item = state.items.find(i => i.id === id);
      if (item) { item.tier = tier; selected = null; save(); render(); }
    }

    function removeCard(id) {
      state.items = state.items.filter(i => i.id !== id);
      save(); render();
    }

    document.querySelector('#add-form').onsubmit = (e) => {
      e.preventDefault();
      const input = document.querySelector('#title');
      if (!input.value.trim()) return;
      state.items.push({ 
        id: 'm' + state.nextId++, title: input.value, tier: 'pool', 
        img: `https://images.unsplash.com/photo-1485846234645-a62644f84728?w=200&sig=${state.nextId}` 
      });
      input.value = ''; save(); render();
    };

    document.querySelector('#reset').onclick = () => {
      if (confirm('초기화할까요?')) { state = { nextId: 9, items: [...initialData] }; save(); render(); }
    };

    load();
    render();
  </script>
</body>
</html>

## 📝 프로젝트 후기 및 보완 사항
*   **이미지 로딩 문제:** 외부 URL을 직접 입력할 때 발생하는 보안 및 경로 문제를 해결하기 위해 Unsplash 랜덤 이미지를 활용하도록 보완하였습니다.
*   **가독성:** 영화 포스터의 색상이 다양하여 제목이 묻히는 현상을 방지하기 위해 텍스트 하단에 반투명 검정 배경을 추가하였습니다.
*   **향후 과제:** 드래그 앤 드롭 외에 모바일 사용자를 위한 터치 인터페이스를 더욱 정교하게 다듬을 예정입니다.
